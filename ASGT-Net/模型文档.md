# ASGT-Net 模型文档

## 概述

ASGT-Net (Adaptive Spectral-Spatial Graph Transformer Network) 是一个用于变化检测任务的深度学习模型，采用双阶段架构设计：

- **SSTEM** (Spectral-Spatial Temporal Encoding Module)：光谱-空间时序编码模块
- **HGLS** (Hierarchical Global-Local Synergy)：分层全局-局部协同模块

---

## 模型架构

### ASGTNet 主模型

```python
class ASGTNet(nn.Module):
    """
    Adaptive Spectral-Spatial Graph Transformer Network (ASGT-Net)
    Architecture:
    1. Spectral-Spatial Temporal Encoding Module (SSTEM)
    2. Hierarchical Global-Local Synergy (HGLS)
    """

    def __init__(self, num_channels=128, patch_size=5, num_classes=2,
                 global_hidden_dim=64, gnn_hidden_dim=6,
                 global_layers=2, gnn_layers=2, num_heads=4, encoder_dim=512):
        super().__init__()
        # Spectral-Spatial Temporal Encoding Module (SSTEM)
        self.sstem = SSTEM(
            num_channels=num_channels, window_size=patch_size,
            num_heads=num_heads, encoder_dim=encoder_dim
        )

        # Hierarchical Global-Local Synergy (HGLS)
        self.hgls = HGLS(
            input_dim=num_channels * 2, hidden_dim=global_hidden_dim,
            num_layers=global_layers, num_heads=num_heads,
            gnn_hidden_features=gnn_hidden_dim
        )

        # 分类器
        self.classifier = ChangeClassifier(global_hidden_dim, num_classes)

        # 权重初始化
        self.apply(self._init_weights)

    def forward(self, x1, x2):
        # 输入预处理
        x1 = x1.flatten(2).transpose(1, 2)
        x2 = x2.flatten(2).transpose(1, 2)

        # Spectral-Spatial Temporal Encoding Module (SSTEM)
        fused_feat = self.sstem(x1, x2)

        # Hierarchical Global-Local Synergy (HGLS)
        fused_output = self.hgls(fused_feat)

        # 分类
        last_hidden = fused_output[:, -1, :]
        return self.classifier(last_hidden)
```

### 模型参数说明

| 参数                  | 默认值 | 说明                     |
| --------------------- | ------ | ------------------------ |
| `num_channels`      | 128    | 输入通道数（光谱波段数） |
| `patch_size`        | 5      | 图像块大小               |
| `num_classes`       | 2      | 分类类别数               |
| `global_hidden_dim` | 64     | 全局分支隐藏维度         |
| `gnn_hidden_dim`    | 6      | 图神经网络隐藏维度       |
| `global_layers`     | 2      | 全局Transformer层数      |
| `gnn_layers`        | 2      | 图神经网络层数           |
| `num_heads`         | 4      | 注意力头数               |
| `encoder_dim`       | 512    | 编码器前馈网络维度       |

## 模块详解

### 1. SSTEM 模块 (Spectral-Spatial Temporal Encoding Module)

SSTEM 负责光谱-空间特征解耦和时序特征融合，包含两个核心子模块：

#### 光谱-空间解耦 (SSDT)

```python
def ssdt_forward(self, x):
    B, L, C = x.shape
    # 光谱特征处理
    spectral_feat = self.spectral_attn(x)
    spectral_feat = self.spectral_norm(spectral_feat)

    # 空间特征处理
    windows = self.window_partition(x)
    B_N, H, W, C = windows.shape
    windows = windows.view(B_N, H * W, C)
    spatial_feat, _ = self.spatial_attn(windows, windows, windows)
    spatial_feat = spatial_feat.view(B, -1, H * W, C).mean(dim=1)
    spatial_feat = spatial_feat.view(B, L, C)

    # 特征融合
    weights = F.softmax(self.fusion_weights, dim=0)
    fused_feat = weights[0] * spectral_feat + weights[1] * spatial_feat
    return self.dropout(fused_feat)
```

**功能特点：**

- **光谱注意力**：使用 Transformer Encoder 层捕获波段间的交互关系
- **空间注意力**：采用窗口化的多头自注意力建模局部空间依赖
- **自适应融合**：通过可学习的权重动态融合光谱和空间特征

#### 时序特征融合 (DRAF)

```python
def draf_forward(self, x1, x2):
    feat_12, _ = self.cross_attn_12(x1, x2, x2)
    feat_21, _ = self.cross_attn_21(x2, x1, x1)
    fused_feat = torch.cat([feat_12, feat_21], dim=-1)
    return self.temporal_norm(fused_feat)
```

**功能特点：**

- **双向交叉注意力**：实现时序特征的双向交互
- **特征互校准**：通过双向注意力实现特征的相互校正

### 2. HGLS 模块 (Hierarchical Global-Local Synergy)

HGLS 负责全局上下文建模和局部空间结构提取，并融合两种特征。

#### 多尺度全局上下文Transformer (MGCT)

```python
def mgct_forward(self, x):
    features = []
    out = x
    for layer in self.global_layers:
        out = layer(out)
        features.append(out)
    multi_scale_feat = torch.cat(features, dim=-1)
    fused_feat = self.global_fuse(multi_scale_feat)
    return self.global_proj(fused_feat)
```

**功能特点：**

- **多层特征提取**：提取不同尺度的全局特征
- **特征金字塔聚合**：融合多层特征获得更丰富的全局上下文

#### 自适应空间图卷积 (ASGC)

```python
def asgc_forward(self, x):
    B, L, _ = x.size()
    adj = self.build_grid_adjacency(L, x.device).unsqueeze(0).expand(B, L, L)
    outputs = []
    out = x
    for linear in self.gnn_layers:
        out = torch.bmm(adj, out)
        out = linear(out)
        out = self.relu(out)
        outputs.append(out)
    multi_scale_feat = torch.cat(outputs, dim=-1)
    fused_feat = self.gnn_fuse(multi_scale_feat)
    return self.local_proj(fused_feat)
```

**功能特点：**

- **拓扑感知图学习**：构建空间邻接图建模局部空间结构
- **多跳邻域聚合**：通过多层图卷积捕获多阶空间依赖

#### 门控跨模态融合 (GCMF)

```python
def gcmf_forward(self, global_feat, local_feat):
    fused = torch.cat([global_feat, local_feat], dim=-1)
    attn_weights = self.softmax(self.fusion_linear(fused))
    weight_global = attn_weights[..., 0].unsqueeze(-1)
    weight_local = attn_weights[..., 1].unsqueeze(-1)
    return weight_global * global_feat + weight_local * local_feat
```

**功能特点：**

- **注意力感知门控**：根据内容动态调整全局和局部特征的权重
- **自适应特征校准**：实现特征的智能融合

## 损失函数

### AdaptiveFocalLoss - 自适应Focal Loss

```python
class AdaptiveFocalLoss(nn.Module):
    """
    自适应Focal Loss损失函数

    特点：
    1. 动态调整类别权重，基于当前batch的类别分布
    2. 自适应调整gamma值，困难样本获得更大的gamma
    3. 添加分类边界增强损失
    """

    def __init__(self, num_classes, gamma=2.0, margin=0.3,
                 margin_weight=0.5, alpha=0.25):
        super().__init__()
        self.gamma = gamma
        self.margin = margin
        self.margin_weight = margin_weight
        self.alpha = alpha
        self.num_classes = num_classes
        self.eps = 1e-8
```

#### 核心特性

1. **动态类别权重**

```python
def _compute_class_weights(self, targets):
    batch_counts = torch.bincount(targets, minlength=self.num_classes).float()
    # 反频率权重 + 平滑因子
    class_weights = 1.0 / (batch_counts + self.alpha)
    class_weights = class_weights / class_weights.sum() * self.num_classes
    return class_weights
```

2. **自适应Gamma调整**

```python
# 自适应gamma：困难样本gamma更大
adaptive_gamma = self.gamma * (1.0 - pt + self.eps)
```

3. **分类边界增强**

```python
def _compute_margin_loss(self, inputs, targets, class_weights):
    # 获取真实类别的logits [B]
    true_logits = inputs[torch.arange(inputs.size(0)), targets]

    # 获取其他类别的最大logits [B]
    mask = torch.ones_like(inputs, dtype=torch.bool)
    mask[torch.arange(inputs.size(0)), targets] = False
    masked_logits = inputs.masked_fill(~mask, float('-inf'))
    max_other_logits = masked_logits.max(dim=1)[0]

    # 计算边界损失
    margin_loss = F.relu(max_other_logits - (true_logits + self.margin))
    return margin_loss
```

#### 参数说明

| 参数              | 默认值 | 说明                  |
| ----------------- | ------ | --------------------- |
| `gamma`         | 2.0    | Focal Loss的gamma参数 |
| `margin`        | 0.3    | 分类边界增强的边际值  |
| `margin_weight` | 0.5    | 边界损失的权重        |
| `alpha`         | 0.25   | 类别平衡因子          |

### DynamicCombinedLoss - 动态组合损失

```python
class DynamicCombinedLoss(nn.Module):
    """
    动态组合损失函数

    结合交叉熵损失（可选Label Smoothing）和自适应Focal Loss，
    并动态调整两个损失的权重。
    """

    def __init__(self, num_classes, lambda_=0.7, smoothing=0.1,
                 lambda_range=(0.3, 0.9), use_dynamic=False):
        super().__init__()
        self.fl_loss = AdaptiveFocalLoss(num_classes)
        self.lambda_ = lambda_
        self.smoothing = smoothing
        self.lambda_min = lambda_range[0]
        self.lambda_max = lambda_range[1]
        self.use_dynamic = use_dynamic

        # EMA平滑的lambda（用于动态调整）
        self.register_buffer('ema_loss_ce', torch.tensor(0.0))
        self.register_buffer('ema_loss_fl', torch.tensor(0.0))
        self.register_buffer('step', torch.tensor(0))
        self.ema_momentum = 0.9
```

#### 核心特性

1. **Label Smoothing支持**

```python
def _compute_smoothed_loss(self, inputs, targets):
    if self.smoothing == 0:
        return F.cross_entropy(inputs, targets)

    num_classes = inputs.size(1)
    log_probs = F.log_softmax(inputs, dim=-1)

    with torch.no_grad():
        # 创建平滑标签
        smoothed_targets = torch.full_like(
            log_probs, self.smoothing / (num_classes - 1)
        )
        smoothed_targets.scatter_(1, targets.unsqueeze(1), 1 - self.smoothing)

    smoothed_ce_loss = - (smoothed_targets * log_probs).sum(dim=1).mean()
    return smoothed_ce_loss
```

2. **动态权重调整**

```python
def _update_dynamic_lambda(self, loss_ce, loss_fl):
    # EMA更新
    self.ema_loss_ce = self.ema_momentum * self.ema_loss_ce + (1 - self.ema_momentum) * loss_ce
    self.ema_loss_fl = self.ema_momentum * self.ema_loss_fl + (1 - self.ema_momentum) * loss_fl

    # 动态调整lambda
    if self.ema_loss_ce > self.ema_loss_fl:
        # CE损失大，减小CE权重
        self.lambda_ = max(self.lambda_min, self.lambda_ * 0.95)
    else:
        # FL损失大，增加CE权重
        self.lambda_ = min(self.lambda_max, self.lambda_ * 1.05)

    self.step += 1
```

#### 参数说明

| 参数             | 默认值     | 说明                               |
| ---------------- | ---------- | ---------------------------------- |
| `lambda_`      | 0.7        | 初始的CE权重（FL权重为1-lambda_）  |
| `smoothing`    | 0.1        | Label Smoothing系数（0表示不使用） |
| `lambda_range` | (0.3, 0.9) | lambda的动态调整范围               |
| `use_dynamic`  | False      | 是否使用动态权重调整               |

## 技术亮点

1. **双路径特征解耦**：同时建模光谱维度和空间维度的特征
2. **时序交互融合**：通过双向交叉注意力实现双时相特征的深度融合
3. **全局-局部协同**：结合全局上下文和局部空间结构
4. **自适应特征融合**：通过门控机制实现特征的智能融合
5. **类别自适应损失**：动态调整损失权重，解决类别不平衡问题
6. **困难样本挖掘**：自适应调整gamma值，聚焦困难样本
